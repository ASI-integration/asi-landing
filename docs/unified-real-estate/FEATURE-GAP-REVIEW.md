## Recommended first slice and acceptance

Use one immutable shared geographic evidence snapshot plus property technical facts, then scenario-specific, deterministic calculations. Residential long-term and STR and commercial whole-versus-split scenarios should reference the same address/evidence revision while retaining distinct revenue/cost assumptions. Existing LocationAnalysis can be an adapter source of labeled model signals, not a second canonical property identity.

For irregular layouts, first use an explicit adjacency graph of measured indivisible spaces, including unequal areas, common circulation and entrances. Enumerate connected partitions within a stated search limit; never report full geometric feasibility or global optimality. Require each unit to retain an allowed entrance/path, usable area, technical capacity and legal-use status; a missing legal review stays unknown. Rank feasible hypothetical plans using the same cash-flow timing/currency/discount conventions, with capex and common-area costs counted once.

Meaningful acceptance: (1) identical evidence revision shared across all scenarios; (2) unequal connected units beat/lose whole property for economically explainable fixture reasons; (3) rejected disconnected/overlapping/over-capacity plans; (4) finite search reports truncation; (5) unknown traffic cannot become measured, unknown legal status cannot become approved; (6) vacancy, free-rent, escalation, shared costs and capex independently checked; (7) no tax/finance assumptions silently supplied; (8) no imported provider/database/executor side effects; (9) no access/paid contract changes; (10) calibration fixtures and thresholds unchanged.
