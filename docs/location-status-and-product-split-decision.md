# Location status and product split decision

_Date: 2026-04-22_

## Decision

### 1) Location module status (current stage)
- Location is considered sufficiently ready for the current stage.
- Deep polishing is paused for now.
- Only critical fixes or obvious breakages should be addressed.

### 2) Priority switch
- Main product focus returns to the Communication module.

### 3) Location product split (two layers)
Location must be delivered as two distinct layers:
1) **Fast demo/test** version available in ~10 seconds.
2) **Full / commercial** version delivered separately.

### 4) Commercial delivery model (not bundled)
The full version must not be bundled into the instant demo flow. It should be sold and delivered separately via a gated paid access flow, for example:
- personal account / dashboard
- dedicated results page
- similar paid access delivery

### 5) Meaning of future work on Location
Future work on Location is primarily productization and monetization flow:
- demo vs full separation
- paywall / checkout / access logic
- delivery of the full report after payment

Not deep core-logic polishing unless something critical is broken.
