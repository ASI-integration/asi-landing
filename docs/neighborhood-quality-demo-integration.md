# Интеграция слоя «комфорт / нагрузка среды» в Location Intelligence Demo

## Где в UI

Блок расположен в детальной колонке под сводкой ASI (`LocationIntelligenceDemo.tsx`), сразу после секции «Почему такой балл?», до аудитории и остальных разделов. Это отдельная карточная секция с лёгким фоном (`bg-slate-950/40`), визуально согласованная с соседними блоками.

## Что показывается (компактно)

1. **Заголовок блока** — `LOC_COPY.envBlockTitle`: RU «Комфорт и среда», EN «Comfort & surroundings» (не дублирует коммерческий индекс).
2. **Короткий лид** — `envLayerLead`: перечисление типов OSM-сигналов и явное разделение от коммерческого балла.
3. **Нагрузка среды** — числовой индекс 0–100, бейдж уровня (`concernLabelRu` / `concernLabelEn`), строка уверенности по карте (`envConfidence`).
4. **Полоска** — та же визуальная шкала, что и раньше; цвет бейджа/полосы привязан к `concernLevel`.
5. **2–4 ключевых причины** — из `reasonsRu` / `reasonsEn`, без строк про полноту карты/уверенность (они вынесены отдельной мелкой строкой под списком).
6. **Нейтральный комментарий** — одна фраза `environmentNarrativeRu` / `environmentNarrativeEn` из движка (`buildNeighborhoodEnvironmentLayer` + `pickEnvironmentNarrative`), отделена лёгкой верхней границей.

## Тексты и логика формулировок

- **Уровни нагрузки** по-прежнему формулируются как нагрузка среды (не «риск района» и не социальные ярлыки): см. `concernLabelRu` в `neighborhood-environment.ts`.
- **Синтез** (`pickEnvironmentNarrative` в `neighborhood-environment.ts`) выбирается в порядке приоритета:
  - сильный коммерческий контекст + заметная нагрузка по картам;
  - относительно спокойный/умеренный фон по прокси OSM;
  - неоднородные сигналы (в т.ч. «жёсткий стек» факторов, низкая уверенность карты при уже заметной нагрузке, или повышенный уровень при среднем коммерческом индексе);
  - иначе — короткий нейтральный fallback по уровню concern.

Так мы различаем «сильно по спросу, но напряжённее по среде», «умеренно по картам», «спорная микролокация — важен точечный отбор» без формулировок вроде «плохой район».

## Обратная совместимость

`patchLegacyLocationAnalysis` использует `mergeNeighborhoodEnvironmentLayer`: у старых объектов анализа без новых полей подставляются значения из `emptyNeighborhoodEnvironmentLayer`, в том числе `environmentNarrative*`.

## Почему так сделано

- **Неперегруженный интерфейс**: один заголовок, один лид, одна строка уверенности, до четырёх буллетов, одна синтезирующая фраза.
- **Профессиональный тон**: только инфраструктурные прокси и оговорки по данным карты; нарратив явно отделяет физическую нагрузку от «качества района» в социальном смысле (см. формулировку для elevated в EN).
- **Единый источник правды**: буллеты остаются в движке, синтез тоже в движке — демо лишь фильтрует сноски про coverage и ограничивает число буллетов для читаемости.

## Как выглядит в выдаче (структура)

```
КОМФОРТ И СРЕДА
[лид: нейтральные признаки OSM, отдельно от коммерческого индекса…]

НАГРУЗКА СРЕДЫ    42    [бейдж: Умеренная нагрузка среды]     Высокая уверенность…
[========····················································]

• [причина 1 из reasonsRu — до 4 строк]
• [причина 2]
…

[при необходимости одна строка: уверенность / полнота карты]

[нижний абзац: environmentNarrativeRu — один нейтральный синтез]
```

## Какие тексты задействованы (RU)

| Элемент | Источник |
|--------|----------|
| Заголовок секции | `LOC_COPY.ru.envBlockTitle` — «Комфорт и среда» |
| Лид под заголовком | `LOC_COPY.ru.envLayerLead` |
| Подпись к числу | `LOC_COPY.ru.envLayerScoreLabel` — «Нагрузка среды» |
| Число 0–100 | `neighborhoodEnvironment.environmentalFrictionScore` |
| Бейдж уровня | `concernLabelRu` из движка (напр. «Умеренная нагрузка среды») |
| Уверенность по карте | `envConfidence(confidence)` |
| Маркированный список | До 4 строк из `reasonsRu`, без сносок про полноту карты |
| Сноска про данные | Оставшиеся строки из `reasonsRu` с признаками «уверенность» / «полнота карты» / «ориентировочный» |
| Итоговый абзац | `environmentNarrativeRu` — ветвление в `pickEnvironmentNarrative` |

## Зачем именно так

1. **Заголовок «Комфорт и среда»** — нейтрально и по делу: не «оценка района», а рамка проживания и окружения.
2. **«Нагрузка среды» + уровень** — прозрачная метрика без слова «риск» в заголовке и без стигматизации.
3. **Ограничение буллетов и вынесение сносок** — меньше шума, фокус на сигналах, а оговорки по OSM не теряются.
4. **Отдельный нарратив** — даёт три профильных смысла (сильный спрос / напряжённая среда; умеренный фон; неоднородность и точечный отбор) одной спокойной фразой, без дублирования коммерческого вывода выше по странице.
