# ASI — автоматическая подсказка следующего шага

**Назначение:** только информационное отражение обязательных проверок и неизменного маршрута «Стригунов 4» на доске GitHub Projects.

- Источник истины — `docs/agent-os/releases/strigunov4-demo.json` в защищённой `main`, **после отдельной приёмки PR #510**.
- Поля проекта — `Допуск` и `Следующее действие`. Поля Status, исходные Issues, PR, релизная карта и серверы не изменяются.
- Workflow `.github/workflows/asi-demo-next-action.yml`: ежечасно (GitHub может задержать расписание), по изменениям карты и вручную; запускается только с `main`.
- Собственный `GITHUB_TOKEN` читает PR #510, точный SHA CI и обсуждения обзора. Проект частный, поэтому для автоматической записи потребуется отдельное **владельческое разрешение** на создание ограниченного секрета `ASI_ROADMAP_PROJECTS_TOKEN` с доступом к Projects. По умолчанию секрета нет: job пишет только информационную сводку в GitHub Actions.
- Запись ограничена двумя полями на шести фиксированных карточках; никаких merge, deploy, SSH, SQL, бронирований, сообщений и изменений защиты GitHub.
- Открытые замечания CodeRabbit → разрешена только работа над исправлениями.
- Успешные CI на текущем SHA без замечаний → требуется **отдельное решение владельца**, не автоматический merge.
- Состояние `ACCEPTED` в JSON/закрытая карточка/обычный зелёный CI не являются физическим доказательством. Пока нет отдельного проверенного SHA-bound механизма приёмки, переход на S4-G2–G6 **блокируется**.
- Статус `release_governance` не считается обязательным лишь потому, что он зелёный. Необходима независимая проверка реально включённой защиты `main`; до неё ремонт staging не допускается автоматически.

**Ограничение v1:** система честно показывает работу и блокировки по S4-G1, но не заявляет полной автоматической приёмки последующих этапов. Эту функцию можно расширить только после устранения двух замечаний Major в #510, внедрения обязательной защиты и подтверждённого формата физических доказательств.

Тест: `node --test scripts/agent-os/__tests__/roadmap-next-action.test.mjs`.
