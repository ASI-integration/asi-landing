# ASI — публичная карта прогресса

Веб-интерфейс строго на русском языке. Внутренний веб-сервис слушает только 127.0.0.1:3101, поскольку порт 3001 уже занят staging Стригунова.

Структура: `ops-map/index.html` — интерфейс, `ops-map/serve.py` — только чтение, `ops-map/refresh.py` — сверка GitHub и изолированных локальных квитанций; `ops-map-status.json` — отражённый файл состояния. Веб-клиент опрашивает JSON каждые 15 секунд; системный таймер сверяет источник каждую минуту. Ветка `asi/ops-map-live` содержит код и проверенные состояния.

Схема status: `schema`, `updatedAt`, `header`, `currentStage`, `stages[5]`, `facts`. Процент бизнес-приёмки меняется только при появлении локальной подтверждённой квитанции `/home/administrator/asi-v11-candidate/ops-map-acceptance.json` с `mode=no-send`, `verified=true`, `sourceSha` равным актуальному main и `passed` из G2–G6. Неподтверждённые события не маркируются как завершённые.

Публичный интерфейс не имеет ключей и маршрутов управления. Никогда не выставлять staging 3001 в интернет, не публиковать внутренние логи или секреты. Системные роли: `asi-ops-map.service` и `asi-ops-map-refresh.timer`.
